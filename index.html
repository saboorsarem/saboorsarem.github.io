What it is

AVA is a desktop dictation app for Persian (fa-IR), English and Russian. It sits on the desktop as a single floating orb, records your microphone locally, recognises speech on this computer, detects the spoken language and types the result straight into the focused window — an editor, a chat, a browser field, any application.

It is a native Windows application (C# / .NET 8 / WinForms) with a local Python speech engine running as a sidecar process. No audio leaves the machine.

Tap · Talk · Done

  1. Tap the orb in whatever app you are already in — it never takes focus.
  2. Talk in Persian, English or Russian; the model transcribes locally, nothing is uploaded.
  3. Tap again — the text is already typed at your cursor. Nothing to paste and no language to choose.

Features

  • Direct typing — recognised text is inserted with Unicode input events, so it works in any app, any keyboard layout. If AVA's own settings window has focus, it returns to the app you were writing in before typing. No clipboard stealing.
  • Never steals focus — the orb is a WS_EX_NOACTIVATE layered window, so the caret stays where you were writing.
  • Automatic language detection — the default Auto mode recognises whether you are speaking Persian, English or Russian on each phrase and decodes it with the matching model. No model switching, no language menu.
  • Visible update badge — when a newer build is published on this site, the orb shows an animated download badge with a rotating ring. Click the badge to open the update page; it disappears when AVA is current.
  • Four engines, your call — Fast (Shenava Koochik, Persian offline CTC, 5× faster than real time, 14.3 % WER), Accurate (Nemotron streaming Persian, text while you speak, 11.0 % WER but slower than real time on a CPU), English (Parakeet 110M in Auto, Parakeet 0.6B v3 manually) and Russian (GigaAM v3 CTC with punctuation). Each language has its own dedicated model instead of a small multilingual one.
  • Persian text clean-up — punctuation, Persian digits, ZWNJ, filler removal.
  • One-file UX — a mint orb with a live equaliser: click to dictate, right click for the radial menu, drag to move, edge snapping, position remembered.
  • Your hotkey — one key is enough. Alt is the default out of the box; click the pill in Settings and press any F-key, Alt or a chord you want, and it is checked with Windows before it is kept.
  • Dashboard & history — words dictated, dictations, streak, speaking time and WPM, plus every transcription with search, copy and delete. Stored locally in %APPDATA%\AVA\history.json, never uploaded.
  • Private by design — audio is processed locally; the only network calls are the one-time model downloads.

Automatic language detection, four models

Auto is the default card. It listens to each phrase, identifies the language on this PC and sends the audio to the right model:

DetectedModelSizeTypical decode
PersianShenava Koochik CTC~0.45 GB0.1 s
EnglishNVIDIA Parakeet 110M CTC~465 MB0.1 s
RussianSber GigaAM v3 CTC~225 MB0.2 s

The language detector is Whisper base, used only to choose one of those three languages — never to transcribe. Only English and Russian labels are trusted; anything else maps to Persian, the app's primary language. That kept all test phrases correct, including Persian sentences the detector called German or Hebrew, while costing about 0.2 s per phrase. All models are warmed at load, so the first phrase is fast too.

The manual cards below remain for when you want to force a model:

ModelLanguageEngineSizeSpeed
Koochik (fast)PersianShenava v1.0, offline CTC~0.45 GBabout 5× faster than real time
Nemotron (accurate)PersianStreaming FastConformer + RNN-T~2.5 GBslower than real time on a CPU
Parakeet (English)EnglishNVIDIA Parakeet TDT 0.6B v3~670 MBabout 1 s per phrase
GigaAM (Russian)RussianGigaAM v3 CTC, punctuation included~225 MBabout 0.3 s per phrase

Auto keeps the three offline models loaded, so changing language costs no model load time. AVA-Setup.exe installs Nemotron during setup; Auto downloads the Persian, English and Russian models on first use (~1.3 GB including the language detector), and the portable zip fetches whichever model you pick. After that AVA works offline.

How it works

C# AVA.exe (WinForms)  <── NDJSON over 127.0.0.1 ──>  bridge/server.py
orb · menu · typing       hello / load / start / stop      torch / sherpa-onnx
                          status / partial / final / level           │
                                                            microphone (16 kHz)

The C# side owns the interface and the text insertion. The Python side owns the model, the microphone and the segmentation; it streams partial/final hypotheses back over a loopback socket.

Download

Grab AVA-Setup.exe above and run it: it unpacks AVA to %LOCALAPPDATA%\AVA with a progress bar, downloads the accurate Nemotron model so both engines are ready, and starts the app. The model download (2.5 GB) can be skipped and happens on first use instead. If you prefer a portable copy, AVA-win64.zip works the same way — unzip it anywhere and run AVA.exe. Nothing else has to be installed: both carry the .NET runtime, an embeddable Python and the speech libraries.

The speech models are downloaded from Hugging Face when first needed. Auto fetches the Persian, English and Russian models plus the language detector (~1.3 GB); the manual cards are 0.45 GB (fast), 2.5 GB (accurate), 670 MB (English 0.6B) and 225 MB (Russian). The setup keeps Nemotron in %LOCALAPPDATA%\AVA\models, the portable copy uses the Hugging Face cache; the orb shows the progress. After that AVA works offline.

SmartScreen — the installer is not code-signed, so Windows may show “Windows protected your PC — Unknown publisher”. Choose More info → Run anyway. A trusted code-signing certificate is the only way to remove this warning for users.

Usage
ActionResult
Left clickstart dictating; click again to stop
Right clickopen the radial menu: AUTO, MODELS, QUIT, SETTINGS, HOME
HotkeyAlt on its own; click the pill in Settings to pick another key
Dragmove the orb; it snaps to the screen edge

The window behind HOME, HISTORY, SETTINGS and ABOUT has four pages: the dashboard (words, dictations, streak, time, WPM, current setup, recent dictations), the history (search, copy, delete, clear all, grouped by day), the settings (launch at startup, update check, feedback, hotkey, activation mode, speech model) and the about page (credits, model licences, privacy). The toolbar has minimise and maximise next to close.

Activation mode decides what the orb and the hotkey do: Tap toggles recording, Hold records only while you press, Both accepts either. A quick tap on the hotkey still toggles in Both.

Switching engines happens on demand: the bridge loads the chosen model and drops the other one, because they do not fit in RAM together. Auto starts in about 7 s once its models are cached and keeps Persian, English and Russian ready; Fast starts in about 3 s, Accurate in 15–45 s, and the English / Russian cards in a few seconds. In Auto each phrase is identified and decoded by the matching model after a short pause; language ID and decoding together take about 0.2–0.4 s, and text reaches the focused app roughly 0.6 s after you stop speaking. During continuous speech Auto types in chunks every 7 seconds.

Text is typed as each phrase is closed by the model — in Auto after about 0.6 s of silence or every 7 s of continuous speech, and in the manual engines after their own pause. It goes straight into the focused app or website; if AVA's settings window happens to be focused, AVA returns to the last external app first. Windows blocks synthetic typing into elevated (admin) apps; AVA copies the text and tells you so. Every finished run is added to the dashboard and history.

Orb stays amberModel still loading, or the engine failed — see %APPDATA%\AVA\bridge.log
Nothing is typedThe target window runs elevated; Windows blocks input from a non-elevated process. The text is copied and AVA shows a note. Run AVA as administrator to type there
Hotkey does nothingAnother app already owns that key — pick another one in Settings
bridge/server.py not foundRun scripts\setup.bat from the repository root
Wrong microphonebridge.log lists the device; set the default input in Windows

Logs, settings and history live in %APPDATA%\AVA\ (ava.log, bridge.log, settings.json, history.json).

Privacy

Audio is captured and recognised on this computer. Recognised text goes to the focused window, to the clipboard, and nowhere else. The only outbound request is the model download from Hugging Face. Record only speech you have the right to record.
